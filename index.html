Two meanings of “token”

The word token means different things to a linguist and to an AI engineer. This tool shows both, using the same text, so you can compare them.

In linguistics

A token is one occurrence of a word in a text. A type is a distinct word. “The cat saw the dog” has five tokens and four types, because the appears twice.

Linguists use these counts to describe vocabulary range, for example with the type/token ratio.

In language models

A token is a unit from a fixed vocabulary that the model reads and writes. It can be a whole word, part of a word, a space plus a word, a punctuation mark or a single byte.

Each token has a number (its ID). The model never sees letters; it sees a sequence of these numbers.

Why it matters

Model limits and prices are counted in tokens, not words. Common English words are often one token each. Rarer words, technical terms, names and numbers tend to need more tokens per word.

How LLM tokenisers are built

Most current models use a method based on byte-pair encoding (BPE). Training starts from single bytes and repeatedly merges the most frequent adjacent pair into a new vocabulary item. After many merges, frequent words become single tokens and rare words are left as several pieces. The tokeniser is fixed before the model is trained, and different models use different vocabularies.

The LLM tab uses OpenAI's published encodings, loaded through the open-source gpt-tokenizer library. Other companies' models (Claude, Gemini, Llama) use their own tokenisers, so their counts will differ. Treat the numbers here as an example of the method, not a count for every model.

Key points

1. Tokens are not words

Language models count text in tokens. Plain English prose usually needs somewhat more tokens than words. Model limits and prices are set in tokens, so a word count is only a rough guide.

2. Common words stay whole

Frequent words such as the, essay or students are usually single tokens. Rare words, technical terms and names are split into pieces. Compare the Everyday and Academic samples to see the difference.

3. Spaces and capitals change tokens

A leading space is usually part of the token, and apple, ␣apple (with a space), Apple and APPLE can have different IDs. Turn on “Show token IDs” to check.

4. Models do not see letters

The model receives a list of token IDs, not characters. This is one reason models sometimes make mistakes when counting letters or spelling words backwards.

5. Numbers and emoji split oddly

Long numbers are broken into chunks of digits, and some emoji take several tokens. Load the Numbers & emoji sample to see how.

6. Two meanings, two purposes

A linguistic token is a word occurrence, defined by the language. An LLM token is a vocabulary item learned from data and chosen for efficiency, not meaning. The two counts answer different questions.
